# BakkieBond prototype

A polished Flutter prototype for a premium friendship app focused on curated small-group meetups in Alkmaar.

## Prototype scope

- Premium onboarding experience
- Home flow for assignment-based meetup discovery
- Upcoming meetup detail screen with hidden venue policy
- Post-event group chat and friend connection concepts
- Profile and preference management UI

## Notes

This repository currently contains a UI-first prototype only. Backend logic, authentication, admin tools, and data persistence are intentionally deferred for a later phase.
